# Weekend Homework — Notion import package

## What is included

- `pages/00-Home.md` — the workspace home page
- `pages/01–05` — one complete project page per build, including the guide and checklist
- `pages/06-Build-Log.md` — a session log template
- `pages/07-Showcase-Submission.md` — the community submission form
- `Project-Tracker.csv` — imports as a Notion database

## Import in about two minutes

1. Download or clone the GitHub repository.
2. In Notion, open **Settings → Import** (or the workspace import option in your Notion version).
3. Choose **Markdown / CSV**.
4. Import the files in this `notion/` folder.
5. Open the imported CSV as a database. Set `Status` as a Select property if Notion imported it as text.
6. Move the Home page to the top of your sidebar and link the five project pages from it.

## How to use it

- Track status in the database.
- Keep build notes and screenshots on the matching project page.
- Log each session in the Build Log.
- When a build passes its checklist, complete the Showcase Submission page and open the GitHub pull request.

## Note

Notion import behaviour varies slightly by workspace and plan. The Markdown files remain readable even if your importer creates them as separate pages rather than nesting them automatically.
