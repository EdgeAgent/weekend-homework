# The Weekend Plan — all five builds in one weekend

Total: roughly 10–12 focused hours. One project is a win; five is a portfolio.

## Friday night (1 hour) — Setup
- Install Claude Code, git, Node/Python (per project), Ollama (for the local-first builds).
- Clone this repo. Read PRINCIPLES.md.
- Pick your order. Recommended: Dashboard → Second Brain → Review Agent → Brand Kit → Life Library (data plumbing first, product last).

## Saturday
- **Morning (2.5h):** Project 1 — Personal Dashboard.
- **Afternoon (3h):** Project 2 — Second Brain.
- **Evening (1.5h):** Project 3 — Daily Review Agent (it reuses the Second Brain's folder habits).

## Sunday
- **Morning (2.5h):** Project 4 — Brand Kit Generator (the sellable one — give it your best energy).
- **Afternoon (2h):** Project 5 — Life Library.
- **Final hour:** Polish pass, README screenshots, one 60-second demo video per project, post your builds.

## Rules of the weekend
- Timebox beats perfection: when the timer ends, write down what's missing and move on.
- If you get stuck for 30 minutes, shrink the step. The guides are ordered so each step runs on its own.
- Everything you finish goes in a public repo. The point isn't the app — it's the proof.
