# Contributing

Thanks for helping turn a reel into something people can actually build.

## Submit a finished build

1. Fork this repository.
2. Copy `showcase/SUBMISSION_TEMPLATE.md` to `showcase/submissions/<your-github-username>-<project-slug>.md`.
3. Complete every required field.
4. Add your entry to `SHOWCASE.md` in the same pull request.
5. Confirm the checklist in the pull-request template.

## Improve a guide

- Keep the guide's structure: outcome, architecture, build order, prompts, definition of done, pitfalls, stretch goals.
- Prefer tested steps over theory.
- If a command or tool version matters, name it.
- Keep personal data out of examples; use fictional sample documents.
- Explain any change from local-first to cloud processing.

## Report a problem

Open an issue with the project name, step number, expected result, actual result, and your environment. Remove secrets and private file contents before posting logs.
